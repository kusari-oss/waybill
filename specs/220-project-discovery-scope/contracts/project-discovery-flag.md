# Contract: `--project-discovery=<mode>` CLI flag

**Feature**: 220-project-discovery-scope | **Related**: FR-001, FR-010

## Surface

New field on `waybill_cli::cli::scan_cmd::ScanArgs`:

```rust
pub project_discovery: crate::generate::project_discovery::ProjectDiscoveryMode,
```

`ProjectDiscoveryMode: clap::ValueEnum` with three variants (`All` default, `RootOnly`, `Strict`).

### Accepted invocations

```
waybill sbom scan --path <dir>                                    # default: All
waybill sbom scan --path <dir> --project-discovery=all            # explicit: All
waybill sbom scan --path <dir> --project-discovery=root-only      # New: RootOnly
waybill sbom scan --path <dir> --project-discovery=strict         # New: Strict
```

### Env-var equivalent (via internal bridge)

```
WAYBILL_PROJECT_DISCOVERY=root-only waybill sbom scan --path <dir>
```

`scan_cmd.rs` bridges the CLI arg to this env var when non-default (mirroring m218's `WAYBILL_EXPERIMENTAL_CROSS_ECOSYSTEM_EDGES` pattern). `scan_fs::scan_path` reads the env var if the flag isn't threaded through. Present as a compat shim for env-var-only invocations (CI scripts that can't easily mutate CLI args).

### Rejected invocations

- `--project-discovery=<nonexistent-value>` → clap parse error, non-zero exit, stderr lists three accepted values.
- `--project-discovery root-only` (space-separated) → clap parse error via `require_equals = true`.
- `--project-discovery=` (empty value) → clap parse error.
- `--project-discovery=ROOT-ONLY` (uppercase) → clap parse error (`rename_all = "kebab-case"` normalizes only rendering, not accepted casing).

## Precedents

- **m219 `--split[=<mode>]`** (`scan_cmd.rs:437-462`): same `ValueEnum` + `require_equals` shape. m220 differs by using `default_value = "all"` instead of m219's `default_missing_value = "workspace"` — m220's flag is always-required semantic (no bare flag = "on"), so a plain default works cleanly.
- **m173 `--warm-go-cache <MODE>`**: same enum-plus-default pattern.

## Clap attribute stack

```rust
#[arg(
    long = "project-discovery",
    value_enum,
    default_value = "all",
    require_equals = true,
)]
pub project_discovery: ProjectDiscoveryMode,
```

- `long`: flag name = `--project-discovery`.
- `value_enum`: uses `ProjectDiscoveryMode: ValueEnum` derive.
- `default_value = "all"`: omitted flag = All variant.
- `require_equals = true`: rejects space-separated forms.

## Default-value invariant

`--project-discovery=all` MUST produce byte-identical output to alpha.68 default behavior. Zero goldens regenerate under this path. Enforced by:
1. `apply_scope_filter` early-returns without cloning inputs when mode = All.
2. C140 doc-scope annotation is silent under All (never emitted).
3. FR-012 INFO log is silent under All (no scope-changed message).
