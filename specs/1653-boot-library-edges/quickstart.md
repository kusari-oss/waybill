# Quickstart: checking spec 1653 by hand

## The table

```sh
grep -P '^9\.10\.3\tbase\t' waybill-cli/src/scan_fs/package_db/nix/haskell_packages/ghc_boot_dependencies.tsv
# 9.10.3  base  4.20.2.0  ghc-internal ghc-prim  package.conf.d
```

To regenerate it, which takes about 7.5 GB of downloads and runs at development time only:

```sh
python3 -I -B scripts/ghc-boot-dependencies.py > waybill-cli/src/scan_fs/package_db/nix/haskell_packages/ghc_boot_dependencies.tsv
```

## A closure document

On a closure golden, regenerated by CI:

```sh
jq -r '.dependencies[] | select(.ref|startswith("pkg:hackage/base@4.20")) | .dependsOn' cdx.json
jq -r '.components[] | select(.name=="ghc-prim") | .properties[] | select(.name=="waybill:boot-library-dependencies") | .value' cdx.json
# {"absent":["rts"],"source":"ghc-boot-dependencies/<observed>"}
jq -r '.metadata.properties[] | select(.name=="waybill:graph-completeness-reason") | .value' cdx.json
```

## Checking the table against nixpkgs

```sh
python3 -I -B specs/1653-boot-library-edges/measurements/nixcache.py /nix/store/<hash>-ghc-9.10.3 ghc-9.10.3/lib/package.conf.d > nix.json
python3 -I -B specs/1653-boot-library-edges/measurements/bindist.py 9.10.3 > bd.json
python3 -I -B specs/1653-boot-library-edges/measurements/cmp.py bd.json nix.json
```
