# Spec 1652 measurements

## SC-001(a): probe build trees *(measured, 2026-11-24)*

`probe/` builds one small CMake project in a container and keeps every build
tree's metadata. Nothing in any build touches the network: dependencies are
local git repositories and tarballs generated by `probe/inner.sh`.

- **Run:** `probe/run.sh <out-dir>`, then `python3 -I -B probe/analyze.py <out-dir>`.
- **Matrix:** CMake 3.25.1 (Debian bookworm), 3.31.6 and 4.0.3 (PyPI) ×
  Ninja 1.11.1 and GNU Make 4.3 × four configurations = 24 build trees.
  Image `debian@sha256:e67eeead736ff7bbe258ef088bff683635c561b1fcfefad0806c1df4ab49ce0e`.
- **Configurations:**
  - `fetch`: nothing installed; every fallback has to fetch.
  - `system`: `hdronly` installed and on `CMAKE_PREFIX_PATH`,
    `-DWITH_EXTRA=ON -DBACKEND=B`, and a file-API query placed before configure.
  - `confonly`: configure only, no build.
  - `failed`: `extproj`'s `URL_HASH` is wrong, so its download fails.
- **Declarations in the probe** (`probe/project/app/CMakeLists.txt`):
  1. `hdronly`: FetchContent from git, with `FIND_PACKAGE_ARGS`.
  2. `urldep`: FetchContent from a URL with a hash.
  3. `neverused`: declared, never made available.
  4. `extra`: gated on `option(WITH_EXTRA OFF)`.
  5. `bdep`: gated on `BACKEND STREQUAL "B"` (a cache string, #1656).
  6. `extproj`: ExternalProject from a URL.
  7. `extgit`: ExternalProject from git.
  8. `MixedCase` (FetchContent) and `ExtMixed` (ExternalProject): mixed-case names, added by T004.

Full output: [`probe-results.md`](probe-results.md). Findings are in
[`../research.md`](../research.md), R1–R6.
